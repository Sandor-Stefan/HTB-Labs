# HTB-Labs

My write-ups and notes from [Hack The Box](https://www.hackthebox.com/), documented in Obsidian while working through the platform.

## Structure

| Folder | Contents |
|---|---|
| `Machines/` | Full write-ups of HTB machines, organized by difficulty and OS (e.g. `EASY/LINUX/`) |
| `Starting Point/` | Notes from the Starting Point beginner track |
| `Challenges/` | Solutions to standalone challenges (web, crypto, forensics, etc.) |
| `Sherlocks/` | Defensive / DFIR investigations, mostly log and artifact analysis |
| `USEFUL THINGS/` | Cheat sheets, commands, and techniques I reuse across boxes |

## Write-up format

Each machine report generally covers:
- **Enumeration**: scanning and service discovery
- **Foothold**: initial access
- **Privilege escalation**: path to root/SYSTEM
- **Lessons learned**: key takeaways

## Disclaimer

These notes are for educational purposes only. Only retired content is published, in line with HTB's rules. Do not use these techniques against systems you don't have permission to test.
